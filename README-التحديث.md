
## إشراف التعليقات والكلمات الممنوعة
أصبح الأدمن ومسؤول/قائد أي جروب مضافاً في `team_leaders` قادرين على حذف أي تعليق من صفحة الأنمي، بينما يستطيع المستخدم العادي حذف تعليقاته فقط. كما أضيف فلتر الكلمات الممنوعة في الواجهة، مع فلتر مركزي داخل Supabase يمنع نشر التعليق حتى لو تم إرسال الطلب مباشرة عبر API.

شغّل ملف `supabase/community_features.sql` كاملًا مرة واحدة فقط. النسخة الحالية مصممة لتضيف الأعمدة الناقصة وتتعامل مع اختلافات المخطط تلقائيًا؛ يفضّل تشغيل `supabase/staff_system.sql` قبلها لتفعيل صلاحيات الأدمن وقادة الجروبات. الترحيل آمن لإعادة التشغيل، ويضيف trigger باسم `anime_comments_blocked_words` وسياسة حذف للمشرفين تعتمد على `is_staff()`.
